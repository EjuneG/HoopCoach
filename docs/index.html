Windows 3 步快速上手

免安装 Python，解压双击即可运行，后续升级仅需 ~0.6 MB 增量热更新

1

下载并完整解压

在 GitHub Releases 下载最新 HoopCoach-Windows-*.zip，解压到任意本地目录（勿在压缩包内直接双击）。

2

双击 HoopCoach.exe

自动探测游戏日志目录（若未找到手动点一次「选择目录」即可永久记住），按需勾选流派与偏科偏好。

3

进入游戏实时护航

进入育成或选人界面后，贴身角标自动显现；局后点「打开作战室网页」即可一键查看评分曲线与 28 训复盘。

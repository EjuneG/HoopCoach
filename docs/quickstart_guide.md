# 1 分钟上手与角标速查

> HoopCoach 全程只读监听游戏本地日志，**不读内存、不 Hook、不自动点击**，放心当成自动同步数据的场边攻略计算器来用。

---

## 1. 贴身角标怎么看

进入选人或育成后，角标会自动贴在对应按钮旁，**鼠标可直接点穿**：

- **橙金 `★ 首选`**：当前综合期望收益（**EV**）最高；灰蓝 `🥈 / 🥉` 为次选对比，方便自己权衡。
- **EV 数值**：已经折算过 **1200 属性折半**、**属性上限**、**失败率** 与 **经理充能** 后的等效分，直接比大小即可。
- **哨冲 / 控体提示**：携带「支援口哨」接近 70 / 100 熟度时，会自动提示留体力或冲线。
- **周末 & 商店**：周末外出优先看角标路线；商店出现高性价比好货（如买药/彩蛋）会直接在右上角和货架旁标出。

---

## 2. 个人角色 / 笔记 / 器材池怎么同步

**不用手动录入！**

- 正常打开游戏玩，或在桌面控制台 / 作战室总览点一下 **「扫描历史战绩」**，程序会自动从本地日志里提取：
  - 已拥有的角色名册
  - 自备笔记与好友借用笔记
  - 自有 SSR 器材与突破/觉醒等级
- 同步完成后，开局选人角标和作战室的 **「笔记与配装」** 就会直接按你的真实库存给出最优组合（未同步前会自动用全图鉴通用高相性方案兜底）。

---

## 3. 几个顺手的小技巧

- **看不到悬浮角标？** 先确认控制台顶部是绿灯「已连接」，再把游戏设为 **无边框窗口化** 或 **窗口化**（独占全屏会盖住桌面置顶窗）。
- **大厅/比赛时角标不见了？** 正常现象。在非决策画面（大厅、加载、过场、比赛）或切到微信/浏览器时，角标会自动隐身不挡视线。
- **随时改流派与偏科**：在桌面控制台切换育成流派（训练流 / 商店流 / 扭蛋流）或指定单属性偏科，**不用重启**，下一帧角标立即生效。
- **局后复盘**：在控制台点 **「打开作战室网页」**，就能看评分走势、单局 28 训逐回合复盘与亏损回合定位。
